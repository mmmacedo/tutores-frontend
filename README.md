# tutores-frontend

Widget de chat embutivel via iframe + painel admin, para o desafio "Plataforma de tutores personalizados" (DOT Digital Group).

> README completo (setup, variaveis de ambiente, fluxo de embed ponta a ponta, decisoes de arquitetura) sera escrito na Etapa 10, apos as rotas `/admin` e `/embed/:tutorId` existirem.

## Setup local (provisorio)

```bash
npm install
cp .env.example .env
npm run dev
```
